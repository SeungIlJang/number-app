## 알려진 차이 — `shot3-perfect.png`

촬영 직후 **v3.6에서 콤보 배수를 HUD로 옮겼습니다.** 그래서 이 한 장만 현재 빌드와 어긋납니다.

- 리본에는 `PERFECT! ×6` 이 있는데 HUD에는 `🔥 12 연속` 만 있습니다
- v3.6부터는 저 조합이 나올 수 없습니다 (배수가 있으면 HUD에도 `×6` 이 같이 보입니다)

**2026-11-11에 "그대로 두기"로 결정했습니다.** 눈에 띄는 차이가 아니고, 다시 찍으면
나머지 3장과 해상도가 안 맞기 때문입니다(아래 참조). 다음에 스크린샷을 갱신할 때
이 장부터 다시 찍으면 됩니다.

## 다시 찍을 때

```bash
python tools/make_store_shots.py <캡처1> <캡처2> <캡처3> <캡처4>
```

브라우저 패널 캡처의 상한은 **디바이스 픽셀 800×1200** 입니다. 9:16 최대는 675×1200.

- 뷰포트를 **337×599** 로 두면 2배로 잡혀 674×1198 이 나옵니다
- **세션이 창에 열려 있지 않으면 1배로 떨어집니다.** 그때는 337×599 그대로 나와
  해상도가 절반이 됩니다. 리로드 직후에 찍으면 2배가 유지될 확률이 높습니다
- 찍기 전에 스크롤바·음소거 버튼·버전 표기를 숨깁니다(스크립트 주석 참조)

촬영용으로 `localStorage` 를 손봤다면(최고·코인·누적) **원래 값으로 되돌린 뒤 바로 reload** 해야
메모리에 있던 값이 다시 덮어쓰지 않습니다.
